A deckbuilder game, where decks consist of set of units. 
For each level you have to place your units on your side of the grid to beat the units on the opponent side. 
You get to pick a random enemy unit after beating each level. 
The idea is that you build decks with different synergies and combo's using the variety of units you get from each level.
